# UI 说明：惠买

- **谁在什么时刻打开**：给在几个渠道对比同款的人。
- **首屏任务句**：同款到手，哪家真便宜。
- **主操作**：按「贴各渠道报价 → 对齐同款规格 → 算到手总价」推进；首屏先给输入和主按钮，结果区在下方或右侧。
- **主信息结构**：超市价签墙；对比、时间线、原文与修订、队列或价签按任务选择，而不是通用卡片堆叠。
- **三种状态**：空状态指到第一步；已有内容显示结果、来源/计算依据和导出入口；失败或待确认时保留已填内容，并在原位置说明缺什么。
- **视觉原型**：超市价签墙。底色、强调色、圆角、边框和数字字体都按该任务重定，遮住产品名后仍能从布局看出用途。
- **解释**：给在几个渠道对比同款的人：把 SKU、规格、运费、券条件和售后期限拆开，只用已满足的条件计算到手总价，保留报价时间和原链接。
